Add the points economy to the existing Performance_Review: Exit_ProtocoL app. Do not change character creation.

TRIAL COSTS BY ROUND

Each round has one trial that tests one attribute. Every player pays the cost from that attribute.

- Round 1 Boot Up: Initiative, cost 2
- Round 2 Sprint 1: Focus, cost 3
- Round 3 The Mirror: Composure, cost 3
- Round 4 Geek Week: Focus, cost 4
- Round 5 Sprint 2: Collaboration, cost 4
- Round 6 Sprint 3: Grit, cost 6
- Round 7 Graduation: no cost

Store these as editable settings so the host can tune them.

HOST ENTERS RESULTS

- After each trial, the host marks each team Win or Loss.

PAYING THE COST

1. Subtract the cost from the player's trial attribute.
2. If the attribute goes below 0, the backup pool pays the shortfall automatically:
   - Bonus attribute: 1 backup covers 1 point.
   - Any other attribute: 2 backup cover 1 point.
3. Any unpaid amount stays as a negative number.
4. Exactly 0 is safe. Below 0 sets status to Glitching.

BACKUP POOL

- Starts at 3. Refills 1 per round. Cap 3. Cannot receive gifts.

EARNING POINTS (at Stats Update)

- Team won the trial: 4 points
- Team lost the trial: 2 points
- Player glitched that round: 1 point
- Round 7: 3 points
- The player places earned points in any attributes, within each attribute's max (10, penalty attribute 7).
- Points are placed before the next trial attribute is revealed.

GIFTS

- A player can send a gift during Open Floor or the gift window.
- The giver picks 1 or 2 points. Cost from the giver's backup:
  - Cooperative: 1 backup per point
  - Independent: 2 backup per point
  - Contrarian: 1 backup per point
- The receiver sees a pop-up: "Gift from [name]: Accept or Decline."
- Accept: the receiver picks which attribute gets the points. Decline: the backup goes back to the giver.
- If a gift brings a negative attribute to 0 or more, cancel the Glitching status.

STATUS FLAGS (the only thing other players see)

- OK: every attribute can cover one more trial.
- At risk: any attribute cannot cover one more trial. Check per attribute: bonus attribute uses points + backup; other attributes use points + half the backup, rounded down. If that is less than the next trial cost, show At risk.
- Glitching: an attribute is below 0 during the gift window.
- Glitched: the glitch locked in.
- Stuck: glitched twice.

GLITCH AND REBOOT

- When the gift window closes, any attribute still below 0 locks in as Glitched. Add 1 to glitch count.
- Reboot: move points from the player's highest attribute into the glitched attribute until it reaches 1. Set backup to 0. The player earns 1 point that round.
- Two attributes below 0 in one round count as one glitch.
- Glitch count of 2 sets status to Stuck. Stuck players become spectators and cannot gift, receive gifts, or graduate.

Show the player's current backup and status on their dashboard. Never show numbers to other players.
